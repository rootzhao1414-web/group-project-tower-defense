# 屏幕自动化：模板匹配 + HSV（实验性）

`tools/` 里是配合「部署建议」的桌面端自动化原型，把模型推荐的部署位置
从「给人看的提示」变成「自动执行的动作」。

它**不含任何模型**（没有权重、没有训练）。本项目真正的模型是
`deployment-model.js`（CNN + MLP 权重）和 `deployment-advice.js`（枚举方案并打分）。
脚本只负责“手”：看屏幕、点鼠标。

## 两段式流程

1. **找按钮** —— 截取整屏，拿 `suggest_btn.png` 做模板匹配
   （`cv2.matchTemplate`，`TM_CCOEFF_NORMED`，默认阈值 0.8）。
   相似度够了就点「部署建议」，让 AI 把推荐格标出来。
2. **找格子** —— 建议出现后地图上会画出虚线高亮框。截屏后先裁掉四周
   （`--roi`，默认 10%）缩小搜索区域，在 HSV 空间提取黄/橙色，用形态学闭运算
   把虚线连成整圈，再按外接框边长与长宽比筛出方块并点它的中心。

闭环：**模型思考 → 建议标出格子 → 脚本点按钮、点格子 → 塔立起来**。
适合无人值守演示、批量跑局采样、回归验证“建议是否真的降低漏怪”。

## 为什么按边长筛，而不是面积

按 `preview-v3.png` 实测：推荐框外部尺寸约 **49 × 48 px**，二值化后是 **19 段**虚线，
每段只有 **21–25 个像素**（约 7×3）。闭运算连成整圈后，它的 `contourArea`
约等于外框面积（≈ 2350），用「面积 20–1000」这个窗口反而会把目标筛掉——那个窗口
更适合“实心小色块”。所以这里改用边长窗口（默认 30–110 px），60 px 的格子在
80%–150% 缩放下都落在里面。

## 运行

```sh
pip install -r tools/requirements.txt

# 1) 先给按钮截一张模板（鼠标移到按钮中心，按 Enter）
python tools/capture-button.py

# 2) 先空跑看坐标，不动鼠标
python tools/screen-autoclicker.py --dry-run

# 3) 坐标对得上再真点
python tools/screen-autoclicker.py
```

`tools/suggest_btn.example.png` 是从 `preview-v3.png` 裁下来的按钮样本（69×31）。
如果你的浏览器渲染和它一致，可以直接改名为 `suggest_btn.png` 用；不一致（换了缩放、
DPI、字体）就用 `capture-button.py` 重截。

运行期间脚本会**抢占物理鼠标**，别同时操作电脑。`Ctrl+C` 停止；把鼠标甩到
屏幕左上角也会触发 pyautogui 的 FAILSAFE 退出。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--template` | `tools/suggest_btn.png` | 按钮模板路径；读不到就退化为只做 HSV 找框 |
| `--threshold` | `0.8` | 模板匹配阈值，调低更灵敏、误检更多 |
| `--roi` | `0.1` | 找格子前裁掉四周的比例，0 表示整屏 |
| `--dilate` | `2` | 闭运算核半径，用来把虚线连成整圈；0 表示不做 |
| `--min-side` | `30` | 格子外接框边长下限（px） |
| `--max-side` | `110` | 格子外接框边长上限（px） |
| `--dry-run` | 关 | 只打印坐标，不点鼠标 |

## 已知限制

- **模板绑环境**：模板匹配对分辨率、浏览器缩放、字体渲染敏感，换机器或改 zoom
  就得重截 `suggest_btn.png`。匹配不到时脚本会每 10 秒打印一次最高相似度，方便判断
  是阈值太高还是模板过期。
- **颜色区间偏宽**：`[10, 80, 80]–[50, 255, 255]` 同时覆盖 `warn` 橙 `#ff9f43`
  与 `gold` `#ffd166`，而 gold 还用在快速敌人和金币、界面强调色上。拿一张游戏截图
  跑同一条掩膜，全图会有两千多个像素散布各处；靠 `--roi` 和时间间隔压误点。
- **全屏绝对坐标**：`mss.monitors[1]` 抓整块主屏，点击用屏幕坐标，
  缩放、窗口位置、多显示器都会导致偏移。这套默认值按“游戏窗口铺满左侧”校准，
  窗口化或换分辨率要重调 `--roi` / `--min-side` / `--max-side`。
- **没有状态机**：只点「部署建议」和部署格，不点「开始波次」，也不判断波次是否结束，
  没有自然退出条件。

## 更稳的替代方案

本项目是纯前端、本地运行的 HTML，可以直接在页面里调 `adviseDeployment()`，
拿到 `recommended.c` / `recommended.r` 后乘 `T` 再加 canvas 偏移，就是精确坐标。
比图像识别准一个量级，也不会误点敌人。
