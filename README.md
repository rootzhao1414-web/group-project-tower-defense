# 塔防 × AI：敌情雷达与部署建议

《人工智能基础》课程项目。在 HTML5 塔防游戏中加入开波前预测：根据当前塔阵与下一波敌人的配置，使用 CNN + MLP 估计漏怪数量，并推荐一座新塔的种类与部署位置。

游戏使用原生 JavaScript、Canvas 和 CSS，双击 `index.html` 即可运行。仓库包含训练好的模型，体验游戏无需安装 Python、Node.js 或下载模型。

## 打开与操作

下载并解压项目后，双击 `index.html`。也可以在项目目录启动本地服务器：

```sh
python -m http.server 8080
```

浏览器访问 <http://localhost:8080>。

1. 点击炮塔卡片或按 `1`–`5` 选塔，再点地图空格建造。
2. 开波前点击「预测下一波」，查看敌人的种类、数量和模型预计漏怪数。
3. 点击「部署建议」，查看推荐塔种、格子与预计改善；点击黄色格子确认建造。
4. 点击「开始波次」。战斗结束后，雷达会显示实际漏怪数。
5. `P` 暂停，`Esc` 或右键取消选择。波间选中已有炮塔后按 `X` 出售。

| 预测 | CNN + MLP 回归整波漏怪数量 |

## AI 是怎样工作的

本项目使用**监督学习**。离线运行游戏，记录布局、敌人配置和实际漏怪数，自动生成训练标签。PyTorch 完成训练后，将权重与标准化参数导出到 `deployment-model.js`；浏览器使用 JavaScript 前向推理。

最终模型有两类输入：

- **地图输入**：6 × 9 × 16，前五个通道分别表示五种炮塔的位置，第六个通道表示地面路线及沿途进度。
- **数值输入**：67 项特征，包括波次、金币、生命、敌人数量与属性、路径覆盖、估算伤害与减速等。

CNN 提取地图特征，与标准化后的数值特征拼接，再由 MLP 输出漏怪比例，乘以本波敌人总数得到预计漏怪数量。

点击预测或部署建议时，只计算规则、路径、特征和神经网络输出，**不会在后台提前打一遍战斗**。离线模拟用于生成训练数据与检验模型建议。

### 预测与建议的边界

- 敌人种类和数量由游戏配波规则计算；预计漏怪数由学习模型预测。
- 模型支持第 1–24 波、当前五塔规则以及保留地面通路的布局。游戏本身可以继续到更后面的波次。
- 每次只建议补一座塔，预计少漏超过 **0.25 只**才显示建议；判断使用未四舍五入的数值。
- 目标是减少整波漏怪数。金币用于限制可选塔种和重新配波，没有额外的省钱目标，也没有跨波次经济规划。
- `0.3`、`1.8` 是连续的模型估计，实际漏怪数仍然是整数。模型可能出错，建议也可能使结果变差。

## 实验结果

四批离线数据共 76,090 条，分为 52,508 条训练、8,763 条验证和 14,819 条测试。同一起始塔阵及波次分组划分，标准化参数只从训练集计算。下表两个模型使用同一数据拆分。

| 模型或策略 | 测试集漏怪数 MAE（只） | 95 个额外布局平均实际漏怪（只） |
|---|---:|---:|
| 保持原布局 | — | 13.97 |
| 随机买一座塔 | — | 11.95 |
| 纯 MLP（同数据重训） | 1.58 | 9.59 |
| CNN + MLP | 1.31 | 9.46 |

CNN + MLP 的预测 MAE 比同数据 MLP 低约 17.1%，部署后的平均实际漏怪减少 0.13 只。预测误差的改善与部署收益是两个指标，不可互相替代。详细测试条件、Boss 结果及局限见 [实验说明](docs/experiments.md)。

## 训练与复现

训练使用 Node.js 生成游戏样本，Python、NumPy、PyTorch 和 scikit-learn 完成训练与评估。完整步骤见 [训练指南](docs/training.md)，包含小样本试跑、完整数据生成、纯 MLP 对照和模型导出方法。

完整训练数据与运行日志保留在本地；仓库提供生成脚本和一份小样本。变更炮塔、地图、敌人或配波规则后，应重新生成数据、训练并评估模型。
