# 🏰 塔防 × AI · Tower Defense

基于 [html5-game-tower-defense](https://github.com/gamelabz/html5-game-tower-defense) 框架改造的塔防小游戏，核心是在传统塔防上加入**可见的 AI 行为**。

零依赖、零构建：双击 `index.html` 或有本地服务器就能玩。

最新版可在敌情雷达中点击「预测下一波」，查看敌人种类、数量和预计漏怪数。点击「部署建议」，CNN + MLP 会评估你买得起的一座新塔，推荐具体塔种和格子。训练方法见 [CNN + MLP 炮塔部署建议](README.v2.md#cnn--mlp-炮塔部署建议)。

## 🎮 玩法

- 点下方按钮选塔 → 点网格空地建造
- 点「开始波次」放敌人进来
- 敌人从左边缘的红圈出生，要走到右边缘的绿色基地
- 漏一个敌人扣 1 点生命，生命归零游戏结束
- 清完一波有金币奖励

## 🧠 AI 部分（本项目的重点）

### 1. A\* 实时寻路

原框架里敌人的路径是写死的数组。现在改成：**每个敌人每次都从自己的位置用 A\* 算法重新算一条到基地最短路**。

所以你能在画面上看到：

- 每个敌人身后拖着一条淡红色虚线 = 它当前规划的路线
- 你建一座塔，所有敌人的路线会**立刻重新规划**（绕路）
- 敌人之间的路线可能不同 —— 它们各自找自己的最优解

### 2. 拆塔模式（状态机）

如果把所有通路完全封死，A\* 会返回 `null`。这时敌人不会傻站着，而是切换状态：

```
march（行进）──封路──▶ attack（拆塔）
                          │
                    塔被拆掉
                          ▼
                      重新寻路
```

- 敌人头顶出现 `⚔` 标记，HUD 的「AI 状态」显示「N 个拆塔中」
- 它们会走向最近的塔并攻击，把塔打掉后路径重新打通
- 塔有血量，被围攻会真的倒下

### 3. 自适应波次

每波敌人不是固定配置，而是先评估玩家战力：

```js
战力 = 塔数量 × 8 + 总输出 × 260 + 存款 × 0.12 + 生命 × 0.6
压力 = clamp((战力 - 30) / 120, 0, 1)
```

战力越高，下一波的**数量、血量、移动速度**都会上调。HUD 提示里会显示当前敌方强度百分比。

## 🌳 三种塔

| 塔 | 造价 | 特点 |
|---|---|---|
| 机枪塔 | 30 | 射速快、伤害低、射程中 |
| 炮台 | 60 | 射速慢、单发高伤、**溅射** |
| 冰塔 | 50 | 伤害低，但**减速 55%**，配合其他塔用 |

## 🚀 运行

**最省事：** 双击 `index.html`。

**推荐：** 用 VS Code 的 Live Server 扩展（右键 `index.html` → Open with Live Server），改代码自动刷新。

**或者：**

```bash
npx serve .
# 或
python -m http.server 8080
```

然后打开 `http://localhost:8080`。

## 📁 目录结构

```
.
├── index.html      # 页面结构、HUD、塔选择按钮
├── style.css       # 深色霓虹 + 玻璃拟态
├── game.js         # 全部游戏逻辑（单文件 IIFE）
└── README.md
```

`game.js` 内部分为八块，按顺序找即可：

```
一、A* 寻路          ← AI 核心
二、敌人 AI          ← 状态机
三、塔与子弹
四、波次（自适应）
五、主循环
六、渲染
七、HUD 与交互
八、启动
```
